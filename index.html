DANE RZECZYWISTE

Bieżące incydenty według Microsoft

Otwarte zgłoszenia z Microsoft Service health (Kondycja usługi), odczytywane przez Microsoft Graph w tenantach testowych, oraz bieżący wpis z publicznej strony stanu status.cloud.microsoft. Odczyt następuje co około 5 minut. Microsoft dzieli zgłoszenia na dwa typy. Incydent (incident, w polskim centrum administracyjnym: zdarzenie) oznacza problem krytyczny: usługa lub jej główna funkcja jest niedostępna. Porada (advisory) oznacza problem o ograniczonym zasięgu, przy którym usługa pozostaje dostępna. Treść komunikatów jest podana w brzmieniu Microsoft, w skrócie.

Regiony Azure: osiągalność

Każdy publiczny region Azure ma własny regionalny punkt końcowy usługi Azure Resource Manager. Sonda wysyła do niego zapytanie co około 5 minut z jednej lokalizacji (GitHub Actions). Zapisuje wynik oraz czas odpowiedzi. Czas odpowiedzi zależy od odległości regionu od lokalizacji pomiarowej, dlatego służy do porównań w czasie, a nie między regionami.

Sondy HTTP

Osiągalność publicznych punktów końcowych Microsoft, mierzona co około 5 minut z jednej lokalizacji (GitHub Actions). Sonda bez uwierzytelnienia potwierdza, że punkt wejścia usługi odpowiada. Nie sprawdza czynności wykonywanych po zalogowaniu.

1HarmonogramGitHub Actions uruchamia pomiar co około 5 minut z jednej lokalizacji.
2ŻądanieZapytanie HTTP GET bez uwierzytelnienia do publicznego punktu końcowego, limit czasu 10 s.
3OcenaWynik jest poprawny, gdy kod odpowiedzi zgadza się z oczekiwanym: 200 dla dokumentów publicznych, 401 dla interfejsów wymagających tokenu. Po błędzie następuje jedna ponowna próba.
4Stan sondy„Dostępna” po poprawnym pomiarze, „Obniżona wydajność” po pojedynczym błędzie, „Niedostępna” po dwóch kolejnych błędach.

Kliknij wiersz, aby otworzyć szczegóły sondy: adres, oczekiwany kod, statystyki i pełny wykres czasu odpowiedzi.

Zgłoszenia

Publiczny kanał stanu Azure (azure.status.microsoft), odczyt co około 5 minut. Kanał obejmuje wyłącznie zdarzenia o szerokim zasięgu; zdarzenia dotyczące pojedynczej subskrypcji są widoczne tylko w Azure Service Health w portalu.

Brak odczytu kanału stanu Azure.

Zapowiedzi zmian zmodyfikowane w ostatnich 14 dniach, odczyt przez Microsoft Graph w tenantach testowych. Tytuły w brzmieniu Microsoft. Odnośnik w kolumnie „Identyfikator” otwiera wiadomość w centrum administracyjnym Microsoft 365 i wymaga logowania administratora.

Brak odczytu Message Center. Odczyt wymaga uprawnienia aplikacyjnego ServiceMessage.Read.All.
